# Снимок PAUK

Снимок рабочего выпуска PAUK от 15 ноября 2026 года.

- `web/` содержит исходники интерфейса 0.12.103.
- Части `controller-checkpoint-0.1.178.tgz.part-*` содержат архив серверных исполняемых файлов 0.1.178 для Linux amd64.
- `controller-checkpoint-manifest.json` содержит контрольную сумму архива и его файлов.
- `support/` содержит службы и скрипты переноса Remnawave, сбросов трафика, удаления резервных входов и публикации объявления INCY.

Снимок содержит код и исполняемые файлы. Рабочая база, настройки окружения, ключи, сертификаты и данные клиентов хранятся отдельно в резервных копиях установки. Исходники Control Plane в корне репозитория относятся к публичной версии 0.1.150.

Собрать архив после скачивания всех частей:

```bash
cat controller-checkpoint-0.1.178.tgz.part-* > controller-checkpoint-0.1.178.tgz
sha256sum controller-checkpoint-0.1.178.tgz
```

Для новой установки и обновления публичной версии 0.1.155 используйте [ветку выпуска для продавцов](https://github.com/djalil055018-ux/vpn-panel/tree/release/remnawave-3.4.11).
