# PAUK 0.12.103

Самостоятельная VPN-панель для Ubuntu 24.04 amd64. Этот выпуск содержит веб-интерфейс 0.12.103 и Control Plane 0.1.178. У каждой установки свои домен, PostgreSQL и учётная запись владельца.

## Установка с нуля

Подготовьте Ubuntu 24.04 amd64, 4 ГБ RAM, 12 ГБ свободного места, входящие TCP-порты 80 и 443. A-запись домена панели должна указывать на IPv4 сервера.

В интерактивной SSH-консоли выполните:

```bash
sudo apt-get update && sudo apt-get install -y git ca-certificates
git clone --branch v0.12.103 --depth 1 https://github.com/djalil055018-ux/vpn-panel.git pauk-0.12.103
cd pauk-0.12.103
sudo bash install-0.12.103.sh
```

Установщик запросит домен, email для Let's Encrypt и пароль владельца. Сначала он устанавливает базовый дистрибутив, затем автоматически применяет 0.12.103. Откройте адрес панели, который указали при установке. Логин по умолчанию — `owner`.

Если у вас уже есть сертификат для этого домена, передайте `--tls-fullchain` и `--tls-key` с абсолютными путями. Для сертификата, полученного в другом месте, настройте его продление у своего провайдера.

## Обновление действующей панели

Поддерживается публичный выпуск 0.1.155 с веб-интерфейсом 0.12.71 или 0.12.72 и Control Plane 0.1.150 в стандартной конфигурации. Для существующей установки скачайте тот же тег в новый каталог и выполните в нём:

```bash
sudo python3 tools/0103-upgrade.py --check
sudo bash install-0.12.103.sh
```

Домен, сертификат, пароли, ключи подписок, клиенты и настройки берутся из установленной панели. Обновление создаёт резервную копию PostgreSQL и файлов конфигурации в `/var/backups/vpn-platform/`. Приём запросов к приложению приостанавливается на время копирования и сверки записей. Если сервисы новой версии не проходят проверку запуска, обновление возвращает прежнюю базу, веб-интерфейс и конфигурацию. Обновление проверяет исходную версию и схему базы перед переключением.

## Перенос из Remnawave и настройки продавца

- В разделе «Перенос Remnawave» можно получить снимок по API или загрузить JSON, проверить клиентов и перенести их в выбранную группу. Поддерживаются версии 3.4.3 и 3.4.11. Переносятся лимит и использованный трафик. Для правил `DAY`, `WEEK`, `MONTH` и `MONTH_ROLLING` создаётся расписание сбросов. При переносе подтвердите часовой пояс исходной панели. Стандартный часовой пояс Remnawave — UTC.
- В «Настройках» владелец может изменить объявление в INCY. Пустое поле скрывает объявление при следующем обновлении подписки.
- Для HTTPS-страниц VPN-нод можно использовать свои домены и сертификаты. Команды установки в панели используют адрес вашей установки.
- Начальный HTTPS-вход создаётся по единственному публичному IPv4 домена панели. Если адресов несколько, укажите адрес действующего HTTPS-входа командой `sudo python3 tools/0103-upgrade.py --initialize-ingress PUBLIC_IPV4`. Для автоматического многозвенного резервирования нужна отдельная настройка транзитного и конечного узлов. Для личного кабинета с покупками и Telegram-бота настройте свои внешние сервисы и их учётные данные.

## Исходники

- `checkpoints/pauk-0.12.103/web/`: исходники веб-интерфейса 0.12.103.
- `checkpoints/pauk-0.12.103/`: проверяемый архив исполняемых файлов Control Plane 0.1.178.
- `control-plane/` и `web/`: исходники базового публичного выпуска, с которого выполняется обновление.
- `native-agents/`: соответствующие исходники агентов 0.2.39, 0.2.42 и 0.2.43.
- `tools/build-release.py`: сборка Linux amd64 из исходников с проверкой манифеста.
- `node-assets.json`: контрольные суммы файлов для подключения VPN-серверов.

Архивы выпуска доступны в GitHub Releases. Сборка требует Go 1.27.3, Python 3.12 и исходных файлов сторонних рантаймов с контрольными суммами, указанными в `tools/build-release.py`. При установке веб-панель собирается через `npm ci` из зафиксированного lock-файла; доступ к npm, Docker Hub, Node.js и репозиториям Ubuntu необходим.
